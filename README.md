# 🗂️ 제도 마스터 — 기계·기초 제도 학습도구 모음

기계제도 · 기초제도 수업용 학습도구 **15개를 한 장에** 모은 허브입니다.
학생에게 **주소 하나만** 주면 되고, 도구는 각자 원래 저장소 그대로 돌아갑니다(이 허브는 링크만 겁니다).

**바로가기 →** https://hongyul67-cpu.github.io/drawing-master-hub/

## 무엇이 좋아지나

1. **링크가 하나로 줄어듭니다** — 도구 15개 주소를 따로 나눠 줄 필요가 없습니다.
2. **`?rc=` 가 자동으로 따라갑니다** — 허브를 결과수집 링크로 열면, 여기서 여는 **모든 도구에 제출 주소가 자동으로 붙습니다.**
   ```
   https://hongyul67-cpu.github.io/drawing-master-hub/?rc=https://script.google.com/macros/s/.../exec
   ```
   이 주소 하나만 학생에게 주면 어느 도구를 풀든 결과가 같은 시트로 모입니다.
3. **진도가 남습니다** — 끝낸 도구에 ✓ 를 누르면 도면 한 장이 조금씩 그려지고(윤곽선 → 표제란 → 3면도 → 중심선 → 치수 → 해칭 → 검도 도장), 다 하면 완성됩니다. (이 기기에만 저장 · localStorage)

## 구성 — 교과서 순서대로 3단계

| 단계 | 도구 |
|------|------|
| **1단계 · 도면을 읽기 위한 기초** | 도면 양식·척도 마스터 · 도면읽기 마스터 · 치수기입 마스터 |
| **2단계 · 도법 (그리는 법)** | 기본 도법 작도 트레이너 · 투상도 마스터 · 3면도 트레이너 · 블록 뷰 매칭 · 단면도 익스플로러 · 단면도 규칙 마스터 · 특수 투상도 비교기 · 전개도 마스터 |
| **3단계 · 기호와 실전** | 기계제도 기호 마스터 · 재료기호 마스터 · 용접기호 마스터 · 자동화설비기능사 실기 도면게임 |

단계 버튼으로 걸러 볼 수 있어, 그 시간에 쓸 것만 학생에게 보여 줄 수 있습니다.

## 도구를 추가하려면

`index.html` 의 `TOOLS` 배열에 한 줄만 넣으면 카드가 생깁니다.

```js
{s:2, e:"📐", n:"도구 이름", u:"저장소이름", b:"기초제도 Ⅲ-2", d:"한 줄 설명"},
```

- `s` = 단계(1·2·3) · `e` = 이모지 · `u` = GitHub Pages 저장소 이름 · `b` = 단원 배지 · `d` = 설명
- 링크는 `https://hongyul67-cpu.github.io/<u>/` 로 자동 생성되고 `?rc=` 도 자동으로 붙습니다.
